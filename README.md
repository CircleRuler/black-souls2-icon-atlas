# BLACK SOULS II · 图标对照表

一个离线的、可搜索的游戏图标速查页。把 `Graphics/System/IconSet.png` 里的 864 个图标和游戏数据表里的 2078 条记录对应起来，方便查「这个图标是什么」「这个状态用哪个图标」。

**在线访问**：https://circleruler.github.io/black-souls2-icon-atlas/

---

## 功能

- **864 格完整图集**，每格标注编号与用途名称
- **2078 条数据**，来自 `States` / `Items` / `Weapons` / `Armors` / `Skills` 五张表
- **按类型筛选**：状态（紫）、物品（绿）、武器（红）、防具（橙）、技能（蓝）
- **搜索**：输入编号直接跳转（如 `185`），或输入名字/描述模糊匹配（如 `黑之魂`）
- **默认折叠**未使用的格子，只显示被数据引用的 393 个图标，页面更紧凑
- **悬停预览**：鼠标划过显示该编号下的前 14 条记录
- **点击查看全部**：弹出详情面板，按类型分组列出该图标的**全部**条目与完整描述（有的图标被 311 条数据共用）

## 使用

单文件、零依赖。直接双击 `index.html` 用浏览器打开即可，不需要联网、不需要服务器。

也可以部署到任意静态托管（GitHub Pages、Vercel、Netlify、对象存储），因为整个页面（含图片）都内嵌在这一个文件里。

## 数据说明

```
图集     IconSet.png   384 × 1300   16 列 × 54 行 = 864 格
数据     2078 条       覆盖 393 个图标
最大编号 781           无一条超出图集范围
```

编号 `0` 在这游戏里是「无图标」的约定，有 57 条数据指向它（不死之身、一段目/二段目等内部状态），不是缺图。

## 技术细节

- 图片以 base64 内嵌在 CSS 变量 `--iconset` 中，全站只存一份
- 无外部字体、无 CDN、无网络请求、无第三方脚本
- 页面体积约 700 KB，首屏一次加载完成
- 数据由本地游戏文件解析生成，未手工录入

## 相关

如果你也想给自己的游戏做一份，思路是：解析 `Data/*.rvdata2`（Ruby Marshal 格式）取出 `@icon_index` 与 `@name`/`@description`，再按 16 列 × 24px 的网格切图集。
